# 分镜关键帧

按「幕 → 场景 → 镜头」三级结构管理分镜脚本、关键帧、AI 提示词与版本记录。

## 目录约定

```text
04-分镜关键帧/
└── 第X幕-场景名/
    └── 镜头号/
        ├── 分镜脚本.md
        ├── 关键帧图像
        ├── 提示词.md
        └── 版本记录.md
```

## 内容范围

- **分镜脚本**：镜头景别、机位、运动、时长、画面内容与诗句对应关系。
- **关键帧**：首帧、尾帧及关键动作帧。
- **AI 提示词**：正向与负向提示词、模型与参数、种子值。
- **版本记录**：每次修改的原因、日期与产出差异。

## 约定

镜头号在同一幕内连续编号，跨幕不重复。已定稿的镜头在版本记录中标注状态，避免后续覆盖。
